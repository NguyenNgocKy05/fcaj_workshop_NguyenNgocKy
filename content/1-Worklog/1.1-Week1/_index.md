### Week 1 Objectives:

* Meet the FCAJ members and understand the program rules.
* Set up an AWS account, control costs and learn basic security concepts (IAM).

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | ---- | ---------- | --------------- | ------------------ |
| 2   | Meet FCAJ members and learn the rules; overview of AWS and its service categories (Compute, Storage, Database, Networking, Security...). | 14/09/2026 | 14/09/2026 | [FCAJ Cloud Journey](https://cloudjourney.awsstudygroup.com/)<br>[AWS Products](https://aws.amazon.com/products/) |
| 3   | Create an AWS Free Tier account; learn about the root user and enable MFA. | 15/09/2026 | 15/09/2026 | [AWS Free Tier](https://aws.amazon.com/free/)<br>[Root user best practices](https://docs.aws.amazon.com/IAM/latest/UserGuide/root-user-best-practices.html) |

| 6   | Install the AWS CLI, configure a profile and practice basic commands. | 18/09/2026 | 18/09/2026 | [AWS CLI getting started](https://docs.aws.amazon.com/cli/latest/userguide/cli-chap-getting-started.html) |

### Week 1 Achievements:

* Understood the AWS overview and how services are grouped by category.
* Created an account, configured AWS Budgets, IAM users/groups/roles and set up the AWS CLI.
